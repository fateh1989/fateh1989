# Research Registry

This file preserves durable research topics and useful sources from prior conversations so future sessions can continue instead of rediscovering the same material. Always verify current site availability, pricing, access level, and content live before relying on it.

## Heavy-equipment reverse parts lookup

### Target workflow

The desired direction is **reverse lookup**, not just ordinary catalog browsing:

`Part Number -> compatible machines -> exact models -> serial ranges -> engine/component -> assembly -> exploded diagram / installation location -> superseded or alternative part numbers`

The long-term value is the relationship graph between a part number and every machine/assembly where it appears.

### General catalog / lookup sources to revisit

- `777parts.com` — large heavy-equipment catalog; model/assembly/diagram browsing and part-number data, with some deeper access requiring subscription.
- AVSpare — heavy-equipment catalog/parts source with CAT/Komatsu/Volvo/Case/New Holland/Kobelco/Hitachi-style catalog material; verify current canonical domain live before use.
- `7zap.com/en/catalog/special/` — special-equipment catalog covering multiple heavy-equipment brands.
- `catalogo.gestordepartes.com/catalog` — Partify / Gestor de Partes catalog.
- `aftermarket.supply` — large multi-brand parts database and part-number search.
- `k-part.com` — especially useful for Komatsu.
- `supply.parts` — multi-brand heavy-equipment parts lookup.

### China-focused sources

- `wstparts.cn` / `wstparts.com` — especially relevant to reverse lookup. Prior searches showed pages where a part number maps to compatible machine models, and some pages include diagrams / parts-manual context.
- CAT Parts China (`parts.cat.com` Chinese locale) — official Caterpillar part pages can expose compatible models and diagrams for some numbers.
- `cgsc108.com` — Chinese construction-machinery documentation/library source; useful as a document/manual corpus even when not a direct reverse-lookup engine.

### Japan-focused sources

- Hitachi Construction Machinery Japan — official parts pages can expose part number -> applicable models for some components.
- Yanmar Construction Japan — model applicability tables for some parts.
- `juko.in` — Japanese heavy-equipment parts source; useful for part number -> model / serial-range / engine relationships on some listings.
- `oota-bihin.com` — Japanese part-number search covering multiple heavy-equipment brands.
- `iwaki-rad.co.jp` — useful for radiator/cooler/condenser OEM-number cross-reference and model applicability.
- `monotaro.com` — some listings expose broad compatibility across multiple equipment brands/models.
- CAT Parts Japan (`parts.cat.com` Japanese locale) — official reverse compatibility for some Caterpillar numbers.

### Korea-focused sources

- `koreapartsexport.com` — useful part-number -> Fits / compatible-model mapping, especially Korean excavator brands.
- `partsbank.co.kr` — large Korean parts database, particularly Doosan/Develon-oriented.
- `topglobalparts.com` — Korean multi-brand parts search.
- `partskorean.com` — Korean genuine-part-number oriented source for Doosan/Hyundai/Volvo/Bobcat-related parts.
- `tradekorea.com` — marketplace/vendor listings sometimes contain detailed compatibility tables; verify vendor claims independently.

### Russia / Eastern Europe-focused sources

- `stcatc.ru` — high-priority source. Multi-brand electronic catalog with part-number search, diagrams, and model/serial/assembly context. Particularly useful for Caterpillar/Komatsu/Hitachi/Volvo/JCB/John Deere/Case/Doosan/Hyundai and others.
- `catalog.tmbk.ru` — large catalog with exploded diagrams, BOM-style relationships, part-number search, analogs/interchangeable numbers; access depth may require registration.
- `komimport.ru` — parts/model lookup, useful but more supplier/store-oriented than a full relationship database.

## Research principle

The key question for every candidate source is not merely “can it show a part?” but:

1. Can a **part number** be the starting query?
2. Does it return **all machines/models** where the number is used?
3. Does it expose **serial number ranges / prefixes**?
4. Does it identify the **assembly/subassembly**?
5. Does it show the **exploded diagram and exact position**?
6. Does it expose **supersession / replacement / cross-reference** numbers?
7. Is the information available without a paid subscription, or at least partially open?

When continuing this research, prioritize sources that satisfy the most of these seven points and save any newly discovered strong sources back into this file.
